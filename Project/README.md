# Hello World TypeScript Project

A minimal TypeScript + HTML project.

## Structure
```
hello-world-ts/
├── src/
│   └── main.ts       # TypeScript source
├── dist/
│   └── main.js       # Compiled JavaScript (auto-generated)
├── index.html        # HTML page
├── tsconfig.json     # TypeScript config
└── package.json
```

## Getting Started

Install TypeScript and compile:
```bash
npm install
npm run build
```

Then open `index.html` in your browser.
